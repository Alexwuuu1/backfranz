# Backfranz - Entrega Hito 3, Día 1

Repositorio: https://github.com/Alexwuuu1/backfranz
Motor: Unity 6000.3.16f1.

## Ejecución
Abrir Assets/Scenes/MenuPrincipal.unity y presionar Play. El menú cambia del campus normal a backrooms después de cinco segundos. Jugar carga Nivel01. Escape abre y cierra la pausa.

## Evidencias
- Backfranz-Hito3.pdf: descripción de escenas y scripts, con capturas.
- Capturas/02-menu-backrooms.png: menú principal.
- Capturas/03-pausa.png: pausa dentro del campus.
- VERIFICACION.txt: resultado de la comprobación automática.
- PRUEBAS.md: lista de verificaciones manuales.

## Organización del proyecto
Assets/Scenes contiene las escenas; Assets/Scripts/UI contiene la lógica de interfaz; Assets/Art/UI/Backfranz contiene fondos, logotipo y fuente. El Canvas organiza botones, paneles y efectos visuales.
La integración del equipo utiliza ramas individuales, develop y main. El historial del repositorio constituye la evidencia de control de versiones.
